# E11 . Cheap-coordinate elimination (O10): dim K for every pattern

`dim K` is the dimension of the left kernel `{ y : y L[balanced rows, expensive columns] = 0 }`; each basis vector is one linearised equation that contains ONLY the cheap (bilinear) coordinate of the outer S-box, so a structure yields `dim K` equations instead of one per outer block.

* `dec` (chosen ciphertext, r_KR on the plaintext side): the outer map is the ENCRYPTION S-box and the matrix is the encryption linear layer L.  Cheap column: DuX position 2 (`a = x2 - x0 x3 - alpha`), YuX position 3 (`z0 = x3 - x0 x1 - x2 - alpha`).

* `enc` (chosen plaintext / CPA): the outer map is `S^{-1}` and the matrix is `L^{-1}`.  Cheap columns: DuX {0,3} (`g` and `f`), YuX {0,1} (`y0` and `y1 - y0`).

Patterns are block positions 0..3 with position 0 leftmost; `1110` means positions 0, 1, 2 balanced.
