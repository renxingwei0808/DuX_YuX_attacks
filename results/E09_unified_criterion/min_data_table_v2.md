对每个 (实例, 方向, 层 ℓ, 模式类) 给出**在 O7 框架内**能让该模式成立的最小
log2 数据量与见证结构。生成命令：

```bash
python experiments/E09_unified_criterion/min_data_v2.py \
    --out results/E09_unified_criterion/min_data_table_v2.md \
    --json results/E09_unified_criterion/min_data_table_v2.json
```

**读法**：`结构` 列里 `B0` = 整块 0 跑遍 F_q^4（O11，首层免费），其余是激活字编号；
`维数` 是特征 2 下每个激活字的仿射子空间维数（F_p 只有全域）。
`dim K` 是 O10 在该模式上的左核维数；**特征 2 上 dim K = 1 的行不可用**（W19-B），
在表里标 ⛔。`†` = 该层存在 D = q 的 Frobenius 边界字（O9 可能救回，判据本身给不出）。
